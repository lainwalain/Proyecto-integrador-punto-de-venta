# MarketGo – Sistema de Punto de Venta y Tienda Online

## Descripción del Proyecto

MarketGo es un sistema de punto de venta (POS) especializado en tiendas de abarrotes, con funcionalidades adicionales para integrar una tienda en línea. El objetivo del proyecto es desarrollar una plataforma moderna, rápida y fácil de usar que permita gestionar productos, ventas, inventarios y pedidos.

## Objetivos del Proyecto

* Crear un punto de venta rápido, confiable y adaptable a negocios pequeños y medianos.
* Diseñar una interfaz intuitiva compatible con computadoras y dispositivos móviles.
* Implementar una sección tipo tienda online para mostrar productos y permitir pedidos.
* Contar con un panel administrativo que permita gestionar:

  * Productos
  * Categorías
  * Usuarios
  * Ventas
  * Reportes
  * Inventarios

## Tecnologías Utilizadas

### Frontend

* HTML5
* CSS3

### Backend

* PHP

### Base de Datos

* MySQL administrado mediante phpMyAdmin
